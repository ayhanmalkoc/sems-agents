# Studio Craft Rules

- Build strong visual hierarchy: one clear primary message, clear section rhythm, no flat walls of text.
- Use responsive layout: grid/flex/clamp/media queries must support narrow and wide screens.
- Keep accessible contrast and readable type scale; avoid low-contrast decorative text.
- Use concrete product copy; no lorem ipsum, TODO, placeholder labels, or generic slop CTAs.
- Use local relative assets only; output must remain export-safe.
- Apply the selected design system tokens consistently through CSS variables.
- Run `studio quality <outputId>` after create/refine and fix warnings that matter.
