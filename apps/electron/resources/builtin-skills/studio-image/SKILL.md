# Studio Image

Use this skill for Studio outputs that need structured image creation. Use the native `studio` tool for lifecycle, keep files under session data, produce complete previewable HTML, and keep output local-first.

## Template library

Templates and components live beside this skill under `templates/` and `components/`. Use `studio templates` to discover canonical ids, then create via native `studio create` or `studio create-project`.
